下载与使用

更新时需要卸载旧版本吗？

一般直接覆盖安装即可。6.26.2 已提供检查更新入口；发现新版后会引导到官方发布页，仍需要用户下载并确认安装。更新前建议备份正在使用的表格。

为什么下载慢或打不开？

安装包由 GitHub 提供下载，网络不可达时请稍后重试。本页面不要求注册或付费，不要从不明镜像下载。也可访问官方发布页查看下载入口。

如何判断 Mac 是否适用？

点击苹果菜单 → 关于本机。如果“芯片”显示 Apple M 系列，可使用此版本；若显示 Intel，此安装包不适用。正式使用前，请先用表格副本验证结果。
