## Smart Checker 6.26.4

- 发现新版本后，更新弹窗显示版本号与更新简介；点击更新打开软件下载网页 https://ztweng.github.io/Smart-Checker/ ，不再跳转 GitHub Releases。
- Windows、Android、macOS 统一升级到 6.26.4。Android 沿用 6.26.3 的签名，可覆盖安装 6.26.3。

- Windows 和 Android 检测到新版后强制更新，无法关闭弹窗或绕过更新继续使用；点击下载后不会解除锁定。
- 已确认的新版要求会保存到本机，重启或断网不会解除锁定；首次检测失败且未确认新版时仍允许本地检查。
- 操作统一为“添加表格”“开始检查”，调整工作区小标题、按钮尺寸，补充正式模板保存入口。
- 保留原版对勾加放大镜软件图标，优化更新弹窗过渡和桌面文件选择器线程。
- 公司：广州大学团委学生社团管理中心；文件版本：6.26.4。
- 模板导出保留完整官方文件名（含 2026.09）；Logo 使用白色底板和独立高清资源，深浅色模式均清晰可见。
- 桌面版默认最大化启动，保留系统标题栏和关闭按钮。
- 社团徽标仅用于软件内部界面，直接使用提供的“会徽.png”，不额外添加底板或边框；快捷方式、安装包、窗口和手机启动图标保持原版不变。

Windows 下载 Setup.exe；Android 下载 .apk。更早的不同签名 Android 旧版须备份数据后卸载安装。
macOS 安装包适用于 Apple Silicon（arm64），未经 Developer ID 签名或 Apple 公证。
旧版需要先覆盖安装本版，才能使用强制更新策略；无法远程修改已安装旧版的程序逻辑。
GitHub 不可访问时，可稍后重试；本版不含静默更新或应用内下载功能。
